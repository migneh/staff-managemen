# 🤖 Staff Manager Bot

بوت داخلي لإدارة **الدعم الفني** (7 رتب) و**الإشراف** (5 رتب) و**الإدارة العامة للسيرفر** (رتبتان: `General Manager` و`Co General Manager`) في سيرفر ديسكورد واحد.
واجهة عربية بالكامل • Node.js + discord.js v14 • SQLite (بدون أي تكلفة).

> الإدارة العامة فريق مستقل ولا توجد له ترقية تلقائية. التعيين والإزالة لا يتمان إلا بقرار من `Server Manager` أو `General Manager` الحالي.

## ✨ الأنظمة

| النظام | الوصف |
|--------|-------|
| 📚 FAQ | قاعدة معرفة بـ 11 تصنيف، لوحة ثابتة تتحدث تلقائياً، بحث، تأكيد قراءة، سجل إصدارات |
| 📡 النشاط | تتبع تلقائي لكل رسالة مع أوزان القنوات وفلتر السبام وتنبيهات الغياب (72/96 ساعة/7 أيام) |
| 🎫 التكتات | قراءة تلقائية لرسالة إغلاق بوت التكتات من قناة محددة — بدون تكامل API وبدون `/log-ticket` — مع منع التكرار والنقاط التلقائية |
| 🏛️ الإدارة العامة | `General Manager` و`Co General Manager` بصلاحيات إشرافية، وتعيين يدوي محمي من Server Manager/GM فقط |
| 🧾 التدقيق والمهام | Audit Log للعمليات الحساسة + مهام متابعة وتأهيل تلقائية للأعضاء الجدد |
| 💾 النسخ الاحتياطي | نسخة SQLite يومية + `/backup` والاحتفاظ بآخر النسخ |
| 🛡️ مخالفات الإشراف | تسجيل كل إجراء إشرافي مع الدليل |
| 🏖️ الإجازات | 5 أنواع، موافقة/رفض بأزرار، حد 30 يوم / 3 مجازين، تذكيرات تلقائية، تجميد الاحتساب |
| 📤 الاستقالات | سرية، قبول (Boss فقط) / رفض / تعليق لمقابلة، إزالة الرتب تلقائياً |
| ⚠️ الإنذارات والملاحظات | 6 أنواع بنقاط وتجميد وإيقاف، ملاحظات سرية |
| 📈 Score | درجة 0-100 بمعايير مختلفة لكل فئة (Helper / Support+ / الإشراف) |
| 🎯 الترقيات | شروط كاملة (مدة + Score + نقاط + تكتات/مخالفات + تقييم + إنذارات + تبريد) — لا ترقية تلقائية |
| 📊 التقارير | فردي، فريق، Leaderboard، تقارير يومية/أسبوعية/شهرية تلقائية مع مقارنة |

## 🚀 التشغيل (3 خطوات)

```bash
npm install
cp .env.example .env     # ضع DISCORD_TOKEN و CLIENT_ID و GUILD_ID فقط
npm run deploy && npm start
```

ثم داخل السيرفر اكتب **`/setup`** (يتطلب Administrator) — معالج تفاعلي بقوائم اختيار:

| الخطوة | كيف |
|--------|-----|
| 🎧🛡️🏛️ الرتب (14) | الدعم والإشراف والإدارة العامة مع **مطابقة تلقائية بالاسم** 🪄 أو اختيار يدوي |
| 📁 القنوات (10) | **إنشاء تلقائي** ✨ ينشئ كاتيجوري `📋 Staff Manager` بالقنوات الداخلية وصلاحياتها الصحيحة |
| 🤖 مصدر التكتات | اختر قناة سجل الإغلاق التي يرسل فيها بوت التكتات رسالته — اختيارية لكنها مطلوبة للتسجيل التلقائي |
| 👑 Server Manager | اربط رتبة المالكين/Server Manager من /setup؛ مالك السيرفر يستطيع دائماً التعيين |
| 📡 قنوات النشاط | اختر قنوات/كاتيجوري التكتات والإدارة والإشراف (اختياري) |

**لا حاجة لنسخ أي معرف (ID).** الإعدادات تُحفظ في قاعدة البيانات وتظهر بشريط تقدم ✅. `config.json` ما زال مدعوماً كمصدر احتياطي اختياري.

### الصلاحيات المطلوبة للبوت في Discord Developer Portal
- Intents: `Server Members`, `Message Content`
- Permissions: إدارة الرتب، إدارة القنوات (للإنشاء التلقائي)، إرسال الرسائل، تضمين الروابط
- **يجب أن تكون رتبة البوت أعلى من كل الرتب الإدارية** — المعالج ينبهك إن لم تكن كذلك

### التسجيل التلقائي للتكتات بدون ربط البوتين
لا يحتاج Staff Manager إلى API أو صلاحيات خاصة من مالك بوت التكتات. بعد اختيار **مصدر سجل التكتات** من `/setup`، يراقب البوت رسائل البوتات في تلك القناة فقط، ويستخرج:

- رقم التكت
- صاحب التكت
- مستلم التذكرة
- من أغلق التكت
- رابط ملف السجل إن وجد

ثم يسجل العملية ويضيف النقاط مرة واحدة حسب `message_id`. ويمكن اختيار `TICKET_LOG_BOT_ID` اختيارياً لتقييد القراءة على بوت محدد. إذا لم تتوفر رسالة سجل صحيحة يبقى `/log-ticket` كخطة احتياطية.

## ⏰ المهام التلقائية

| المهمة | التوقيت |
|--------|---------|
| فحص الغياب | كل 30 دقيقة |
| تفعيل/إنهاء الإجازات والتذكيرات | يومياً 00:05 |
| نسخة احتياطية لقاعدة البيانات | يومياً 00:15 |
| التقرير اليومي | يومياً 09:00 |
| التقرير الأسبوعي + Leaderboard + نقاط الأسبوع + تقارير فردية بالخاص | الجمعة 10:00 |
| التقرير الشهري + مقارنة + أفضل إداري + تحليل الاستقالات | أول كل شهر 11:00 |

المنطقة الزمنية تُضبط عبر `TZ` في `.env` (الافتراضي `Asia/Riyadh`).

## 🔌 طريقة قراءة سجل بوت التكتات
التسجيل التلقائي معزول في `services/ticketLogs.js`: لا يوجد ربط بين البوتين. Staff Manager يقرأ رسالة الإغلاق من قناة مخصصة، يحلل الـ Embed/النص، ثم يحفظ `source_message_id` لمنع التكرار. تنسيق الرسالة الحالي يدعم عبارات مثل `صاحب التكت` و`مستلم التذكرة` و`الي قفل التكت` و`رقم التكت` مع منشنات Discord.
