# 🤖 Staff Manager Bot

بوت داخلي لإدارة فريقي **الدعم الفني** (7 رتب) و**الإشراف** (5 رتب) في سيرفر ديسكورد واحد.
واجهة عربية بالكامل • Node.js + discord.js v14 • SQLite (بدون أي تكلفة).

## ✨ الأنظمة

| النظام | الوصف |
|--------|-------|
| 📚 FAQ | قاعدة معرفة بـ 11 تصنيف، لوحة ثابتة تتحدث تلقائياً، بحث، تأكيد قراءة، سجل إصدارات |
| 📡 النشاط | تتبع تلقائي لكل رسالة مع أوزان القنوات وفلتر السبام وتنبيهات الغياب (72/96 ساعة/7 أيام) |
| 🎫 التكتات | تسجيل يدوي عبر Modal مع التقييم والمدة + نقاط تلقائية |
| 🛡️ مخالفات الإشراف | تسجيل كل إجراء إشرافي مع الدليل |
| 🏖️ الإجازات | 5 أنواع، موافقة/رفض بأزرار، حد 30 يوم / 3 مجازين، تذكيرات تلقائية، تجميد الاحتساب |
| 📤 الاستقالات | سرية، قبول (Boss فقط) / رفض / تعليق لمقابلة، إزالة الرتب تلقائياً |
| ⚠️ الإنذارات والملاحظات | 6 أنواع بنقاط وتجميد وإيقاف، ملاحظات سرية |
| 📈 Score | درجة 0-100 بمعايير مختلفة لكل فئة (Helper / Support+ / الإشراف) |
| 🎯 الترقيات | شروط كاملة (مدة + Score + نقاط + تكتات/مخالفات + تقييم + إنذارات + تبريد) — لا ترقية تلقائية |
| 📊 التقارير | فردي، فريق، Leaderboard، تقارير يومية/أسبوعية/شهرية تلقائية مع مقارنة |

## 🚀 التشغيل

```bash
npm install
cp .env.example .env            # ضع التوكن و CLIENT_ID و GUILD_ID
cp config.example.json config.json   # ضع معرفات الرتب والقنوات
npm run deploy                  # تسجيل أوامر السلاش في السيرفر
npm start
```

### الصلاحيات المطلوبة للبوت في Discord Developer Portal
- Intents: `Server Members`, `Message Content`
- Permissions: إدارة الرتب (للترقيات والاستقالات)، إرسال الرسائل، تضمين الروابط
- **يجب أن تكون رتبة البوت أعلى من كل الرتب الإدارية** ليتمكن من تعديلها

## ⚙️ الإعداد (`config.json`)

- `roles.support` / `roles.moderation`: معرف رتبة الديسكورد لكل رتبة إدارية (أعلى رتبة يملكها العضو هي المعتمدة)
- `channels`: القنوات العشر المطلوبة (`staff-faq`, `staff-updates`, `leave-requests`, `resignation-requests`, `staff-logs`, `performance-reports`, `staff-alerts`, `ticket-logs`, `mod-logs`, `manager-review`)
- `activityChannels`: معرفات القنوات أو الكاتيجوري لكل نوع (`ticket` 50% • `staff` 25% • `moderation` 25%) — الباقي يُعتبر عام 10%
- أي قناة غير معرّفة تُعامل تلقائياً كتكت إذا كان اسمها يبدأ بـ `ticket-`

## ⏰ المهام التلقائية

| المهمة | التوقيت |
|--------|---------|
| فحص الغياب | كل 30 دقيقة |
| تفعيل/إنهاء الإجازات والتذكيرات | يومياً 00:05 |
| التقرير اليومي | يومياً 09:00 |
| التقرير الأسبوعي + Leaderboard + نقاط الأسبوع + تقارير فردية بالخاص | الجمعة 10:00 |
| التقرير الشهري + مقارنة + أفضل إداري + تحليل الاستقالات | أول كل شهر 11:00 |

المنطقة الزمنية تُضبط عبر `TZ` في `.env` (الافتراضي `Asia/Riyadh`).

## 🔮 التكامل المستقبلي مع بوت التكتات
التسجيل اليدوي معزول في `commands/logging.js` — عند توفر لوقز تلقائية يكفي إدراج صف في `ticket_metrics` واستدعاء `points.add` دون تغيير أي نظام آخر.
